# VPN Tele-Monitor v3.0

Телеграм-бот для комплексного мониторинга VPN-сервера (WireGuard), учета трафика пользователей, управления пира
ми и отправки уведомлений в Telegram.

Этот бот превращает ваш VPN-сервер в полноценный сервис с блэкджеком и... графиками.

## 🚀 Возможности

* **Системный мониторинг**: Отслеживание CPU, RAM, Uptime и сетевой нагрузки (Up/Down).
* **Учет трафика**: Сбор данных по RX/TX для каждого пира WireGuard с сохранением в `SQLite`
* **Система квот**: Оповещение администратора при превышении пользователем месячного лимита (в ГБ).
* **Публичный Dashboard**: Автоматически обновляемое сообщение в Telegram-канале со статусом сервера.
* **Отчеты**:
    * **Ежедневный (Админу)**: "Топ" пользователей за день и их месячное потребление.
    * **Ежемесячный (В канал)**: Публичный отчет об общем трафике и самом активном дне.
* **Уведомления**:
    * Алерты о высокой нагрузке (CPU/RAM).
    * Еженедельный SpeedTest в канал.
    * Ежемесячное напоминание об оплате (в канал и админу).
* **Управление пирами**:
    * `/block <имя>`: Мгновенно блокирует пира (удаляет его из `wg` интерфейса).
    * `/unblock`: Перезапускает сервис `wg-quick` для восстановления всех пиров.
* **Статистика**:
    * `/online`: Показывает, кто в сети (по последнему handshake).
    * `/chart <имя>`: Генерирует график потребления трафика за 7 дней (для пира или общий).

## 🛠️ Установка и настройка

### 1. Системные зависимости

Бот ожидает, что на сервере (Debian/Ubuntu) установлены:

* `python3` и `python3-venv`
* `wireguard-tools` (для утилиты `wg`)
* `speedtest-cli` (для тестов скорости)

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip wireguard-tools speedtest-cli
```

### 2. Клонирование и установка Python-пакетов

```bash
git clone [https://github.com/yessshka/tele-monitor.git](https://github.com/yessshka/tele-monitor.git)
cd tele-monitor
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Конфигурация (`.env`)

Создайте файл `.env` из примера и отредактируйте его.

```bash
cp .env.example .env
nano .env
```

* `BOT_TOKEN`: Токен от @BotFather.
* `ADMIN_CHAT_ID`: Ваш ID в Telegram (узнать у @userinfobot).
* `CHANNEL_ID`: ID канала (в формате `-100...`), куда бот будет постить "табло" и отчеты.
* `PEER_NAMES`: JSON-строка, связывающая IP пиров с их именами. **Это обязательно!**
* `PEER_QUOTAS`: JSON-строка с квотами в ГБ для пиров.

### 4. ⚠️ Настройка Sudo (Критически важно!)

Для работы команд `/block`, `/unblock` и `/active_wg` боту нужны права `sudo` на выполнение команд `wg` и `systemctl` **без пароля**.

1.  Узнайте, из-под какого пользователя вы будете запускать бота (например, `ubuntu`).
2.  Создайте новый файл для `sudoers`:

    ```bash
    sudo visudo -f /etc/sudoers.d/wg_bot
    ```

3.  Вставьте в этот файл следующие строки, **заменив `your_user`** на имя вашего пользователя:

    ```ini
    # Разрешить пользователю 'your_user' управлять WireGuard
    your_user ALL=(ALL) NOPASSWD: /usr/bin/wg
    
    # Разрешить 'your_user' перезапускать сервисы wg-quick
    your_user ALL=(ALL) NOPASSWD: /bin/systemctl restart wg-quick@*.service
    ```

    *Пути к `wg` (`/usr/bin/wg`) и `systemctl` (`/bin/systemctl`) могут отличаться. Проверьте их командами `which wg` и `which systemctl`.*

### 5. Запуск

Убедитесь, что вы находитесь в активированном окружении (`source venv/bin/activate`).

```bash
python3 main.py
```

Для постоянной работы рекомендуется настроить `systemd` сервис.

## 🤖 Команды бота

### Для всех

* `/start` - Приветственное сообщение и список команд.
* `/monitoring` - Текущая нагрузка сервера (CPU, RAM, Net, Uptime).
* `/online` - Показывает, кто сейчас в сети (handshake < 3 мин).
* `/active_wg` - Полный вывод `wg show` (техническая информация).
* `/chart` - Общий график потребления трафика за 7 дней.
* `/chart <имя_пира>` - График потребления для конкретного пира.

### Только для Админа

* `/broadcast <текст>` - Отправить объявление в публичный канал.
* `/block <имя_пира>` - Заблокировать пользователя (удаляет пира до перезапуска).
* `/unblock` - Разблокировать всех (перезапускает сервис `wg-quick`).
* `/force_dash` - Принудительно обновить "табло" в канале.
* `/test_quota` - Принудительно запустить ежедневный отчет (для теста).
* `/test_speed` - Принудительно запустить тест скорости.
